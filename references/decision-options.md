## 1. Option-writing rule

When information is missing:

- offer two or three mutually exclusive choices;
- put the recommended option first and label it `Recommended` or `推荐`;
- explain the user-visible result, production tradeoff, or risk in one sentence;
- include a reply shortcut such as “回复 1 / 2 / 3，或回复‘全部按推荐’”;
- tailor options to supplied artifacts instead of blindly repeating this reference;
- ask only one to three decisions per turn.

Do not overwhelm the user with a settings catalog. Resolve high-impact choices first and reveal later choices when relevant.

## 2. Standard input options

### Product evidence

1. **源码压缩包或仓库（推荐）：** 能还原真实组件、状态、字体、图标和点击逻辑，适合最终商用品质。
2. **可访问的真实产品 URL：** 可以观察真实界面，但登录态和隐藏功能可能仍需源码或说明。
3. **截图/录屏探索稿：** 只能做方向验证，不得声称完整复刻真实功能。

### Brand assets

1. **提供 Logo、字体、图标、配色和官网（推荐）：** 品牌一致性最高。
2. **从源码提取：** 适合资产已包含在项目里的情况。
3. **先用中性占位：** 仅用于探索预览，最终必须替换或明确授权。

## 3. Creative-direction options

### Visual balance

1. **真实 UI＋创意文字混合（推荐）：** 同时保证功能可信和宣传片冲击力。
2. **UI 演示为主：** 更像产品操作发布，信息具体但视觉抽象度较低。
3. **发布会文字/图形为主：** 卖点更强烈，但必须保留足够真实产品证据。

### Story structure

1. **问题→操作→结果→价值（推荐）：** 最容易建立逻辑并让用户记住主卖点。
2. **功能递进：** 适合多个能力形成完整工作流。
3. **发布会揭晓：** 适合新品发布，先制造期待再集中展示能力。

### Recreation priority

1. **动画语言贴近、产品与品牌真实（推荐）：** 复制节奏、镜头和转场逻辑，不偷用参考资产。
2. **高度贴近参考结构：** 更接近参考片，但需确认版权边界和产品几何差异。
3. **仅作灵感：** 保留少量气质，创作自由度最大。

## 4. Duration and pacing options

1. **25–35 秒精炼版（推荐社媒）：** 主卖点突出，通常容纳 6–10 个有效场景。
2. **40–60 秒完整版：** 能展示更多真实流程和结果，但需要更强的节奏控制。
3. **15–20 秒短广告：** 传播快，只适合一个主卖点和极少数证明场景。

For readability, recommend extending a scene before shrinking important text. Keep beat-synced element motion even when the scene itself is longer.

## 5. Reference and music options

### Reference video

1. **上传原视频文件（推荐）：** 可读取原始 FPS、音频并密集抽帧分析转场。
2. **提供可下载链接：** 先确认可访问与使用权限。
3. **只给截图：** 只能分析版式，无法可靠分析缓动、速度和无缝转场。

### Music

1. **用户提供并确认可用的音乐（推荐）：** 可精确找高潮、截取片段并卡点。
2. **使用可商用授权音乐：** 需要用户确认来源和许可范围。
3. **暂时无音乐：** 可先做逻辑预览，但最终节奏和高潮仍需二次编排。

## 6. Output options

1. **2K60 MP4/H.264＋AAC（推荐 UI 宣传片）：** 文字较清晰、动作顺滑，负载明显低于 4K60。
2. **1080p60 MP4：** 兼容和速度更好，适合大多数社媒与手机观看。
3. **4K30 或 4K60：** 细节更高；4K60 负载、临时空间和闪帧风险最高。

Always adapt the recommendation to platform, hardware, duration, and smallest target screen. Confirm export separately after preview approval.

## 7. Decisions that cannot be defaulted

Require explicit confirmation for:

- product claims unsupported by source;
- music, font, image, video, or code licensing;
- credentials, authentication, private data, or external messaging;
- exact product/source version when versions visibly differ;
- destructive overwrite or deletion;
- public deployment or publishing;
- final export request and exact export specification.
