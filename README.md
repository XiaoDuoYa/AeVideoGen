# AeVideoGen Skill

AeVideoGen Skill 是一个用于制作商业级 AE 风格产品发布、功能介绍、UI 交互演示和宣传视频的创作工具包。它提供从创意策划、参考视频分析、素材重构到网页动画渲染和质量检查的完整工作流。

AeVideoGen Skill is a toolkit for creating commercial-grade AE-style product launches, feature explainers, UI interaction demos, and promotional videos. It provides an end-to-end workflow covering creative planning, reference video analysis, asset reconstruction, web-based motion rendering, and quality assurance。
